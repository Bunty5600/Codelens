# Contributing to CodeLens AI

Thank you for your interest in contributing to CodeLens AI!

## How to contribute

1. Check existing issues before starting substantial work.
2. For significant changes, open an issue first to discuss the proposed approach.
3. Fork the repository and create a focused branch from the current default branch.
4. Keep changes small and clearly scoped.
5. Run the relevant checks and tests before submitting.
6. Open a pull request against the default branch and explain the problem, solution, and testing performed.
7. Respond respectfully to review feedback. A maintainer may request changes before merging.

## Contribution requirements

- Submit only code, documentation, and other material that you created or are legally permitted to contribute.
- Identify third-party code or assets and provide their applicable license and attribution.
- Do not commit API keys, passwords, tokens, private data, or other secrets.
- Follow the project's existing style and avoid unrelated changes.
- By submitting a contribution, you agree that your contribution will be made available under the repository's MIT License. You retain copyright in your original contribution; this statement does not transfer ownership to the maintainer.

## Review and merging

All pull requests are subject to maintainer review. Opening a pull request does not guarantee acceptance. Maintainers may request changes or close a pull request that is out of scope, unsafe, or inconsistent with the project.

## Attribution

The project is maintained as CodeLens AI. Please preserve existing copyright and license notices. Contributors may be credited through GitHub's contribution history, release notes, or project documentation.

Thanks for helping improve CodeLens AI!
